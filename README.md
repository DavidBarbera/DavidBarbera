# Hi, I'm David Barbera

**Speech ML Engineer & Applied Scientist** · PhD Cognitive Neuroscience (UCL)

I build speech recognition systems for people whose speech doesn't fit the patterns mainstream AI was designed for — speakers with dysarthria, aphasia, and other neurological conditions.

### What I'm working on

- 🗣️ [**Whisper Clinical Speech**](https://github.com/DavidBarbera/whisper-clinical-speech) — LoRA fine-tuning of Whisper for dysarthric speech. 47% WER reduction with 0.73% of parameters. [Model on HuggingFace](https://huggingface.co/dbarbera/whisper-small-torgo-dysarthria-lora)
- ⚡ [**Neural Inference**](https://github.com/DavidBarbera/Neural_Inference) — C++ header-only framework for on-device neural network inference
- 🔊 [**Few-Shot Sound Event Detection**](https://github.com/DavidBarbera/Few-Shot_Sound_Event_Detection_with_Prototypical_Neural_Networks) — Metric-based meta-learning for audio classification
